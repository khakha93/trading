# 한국투자증권 미국주식옵션 시세조회 프로그램

한국투자증권 Open API를 활용하여 미국주식옵션(해외옵션)의 시세를 조회하는 파이썬 프로그램입니다.

## 1. 사전 준비 (Conda 가상환경 및 패키지 설치)

웹 대시보드와 코어 시뮬레이터 구동에 필요한 패키지들을 가상환경에 설치해야 합니다. 아래 명령어를 실행하십시오.

```bash
pip install -r requirements.txt
```


## 2. API 설정

1. 프로젝트 루트 폴더에 있는 `config.env.template` 파일을 복사하여 `.env` 또는 `config.env` 파일을 생성합니다.
2. 한국투자증권 Developers 센터에서 발급받은 실전투자용 `APP_KEY`와 `APP_SECRET`을 설정 파일에 입력합니다.

### Streamlit Cloud 배포 시
Streamlit Cloud에서는 로컬 `.env` 파일 대신 앱의 Secrets를 사용합니다.

1. Streamlit Cloud의 앱 설정 > Secrets에 아래 형식으로 입력합니다.

```toml
APP_KEY = "발급받은_실전투자_APP_KEY"
APP_SECRET = "발급받은_실전투자_APP_SECRET"
CUST_TYPE = "P"
```

2. 로컬 실행 시에는 `.env` 파일을 계속 사용하면 됩니다.
3. 코드에서는 `.env` → 환경 변수 → Streamlit Secrets 순서로 값을 읽습니다.

> **주의**: 한국투자증권 해외옵션 조회 API는 **실전투자** 환경에서만 조회 가능하며, 모의투자는 지원하지 않습니다.

```env
APP_KEY=발급받은_실전투자_APP_KEY
APP_SECRET=발급받은_실전투자_APP_SECRET
CUST_TYPE=P
```

## 3. 실행 방법

명령 프롬프트(CMD) 또는 파워셸(PowerShell)을 열고 아래 중 원하는 형태로 실행합니다.

### A. 실시간 대화형 웹 대시보드 구동 (추천)
드롭다운을 통한 간편한 옵션 검색과 마우스 오버 툴팁이 활성화된 Plotly 그래프 및 실시간 파라미터 시뮬레이션을 제공하는 GUI 화면을 실행합니다.

```bash
# 가상 환경(trading_env) 활성화 후 실행
python run_app.py
```
실행 후 브라우저에서 **http://localhost:8502** 로 자동 접속됩니다.

---

### B. 콘솔 기반 실행 방법
기존 콘솔 터미널 환경에서도 아래 명령어들을 통해 시세를 조회할 수 있습니다.

#### B-1. 기초자산 티커로 옵션 목록(Option Chain) 조회
기초자산의 티커만 입력하여 실행하면, **마스터 파일을 자동으로 다운로드 및 압축 해제**하여 현재 거래 가능한 전체 옵션 코드 목록을 가독성 높은 표로 출력합니다.

```bash
# 프록터 앤 갬블(PG)의 모든 상장 옵션 조회
python trading_option.py PG

# 애플(AAPL)의 모든 상장 옵션 조회
python trading_option.py AAPL
```

### B. 특정 옵션 코드로 실시간 시세 조회
단일 옵션 코드를 인수로 전달하면 한국투자증권 API로부터 해당 종목의 실시간 시세를 텍스트로 즉시 조회합니다. **(이 모드에서는 수익곡선 팝업창이 뜨지 않습니다.)**
*(종목 코드 중간에 공백이 포함되어 있으므로 **반드시 따옴표(`"`)로 감싸서 입력**해야 합니다.)*

```bash
# PG 2026년 7월물 콜옵션 $145.0 단순 시세 조회
python trading_option.py "1PGN26 C145.0"
```

### C. 만기수익곡선(Payoff Diagram) 시각화 및 합성 전략 분석
`-p` 또는 `--payoff` 스위치 옵션을 사용하여 하나 이상의 옵션을 넘기면, 해당 옵션들의 실시간 프리미엄을 자동으로 일괄 조회하여 **개별 또는 합성(Combined) 만기수익곡선**을 팝업하고 `payoff_diagram.png`로 저장합니다.

* **입력 규격**: `"옵션코드[:포지션(buy/sell)][:수량(정수)]"`
  - 포지션을 생략하면 기본값 **`buy` (매수)** 로 자동 처리됩니다.
  - 수량을 생략하면 기본값 **`1` (1계약)** 로 자동 처리됩니다.
  - 예: `"PGZ26 C145.0"` ➡️ **매수 1계약**으로 자동 해석
  - 예: `"PGZ26 C150.0:sell"` ➡️ **매도 1계약**으로 해석
  - 예: `"PGZ26 C150.0:sell:2"` ➡️ **매도 2계약**으로 해석

```bash
# 1. 단일 옵션 만기수익곡선 조회 (기본 매수 1계약)
python trading_option.py -p "1PGN26 C145.0"

# 2. 복수 옵션을 조합한 합성 전략 시각화 (예: 콜 불 스프레드 - 매수 1계약 + 매도 1계약)
python trading_option.py -p "PGZ26 C145.0" "PGZ26 C150.0:sell"

# 3. 가중치 수량이 포함된 합성 전략 시각화
python trading_option.py -p "PGZ26 C145.0:buy:1" "PGZ26 C150.0:sell:2"
```

### D. 만기 전 특정 날짜(만기 전) 수익 곡선 및 예상가 분석 (신규 기능)
블랙-숄즈(Black-Scholes) 옵션 가격 결정 모형을 활용하여 시간이 흐름에 따라 옵션의 시간가치(Theta)가 감소하는 효과와 내재변동성(Vega)의 변화를 반영한 예상 옵션 가격 및 포트폴리오 합성 수익 곡선을 분석하고 시각화할 수 있습니다.

* **추가 옵션 파라미터**:
  - `-d / --days-to-expiry` (정수): 분석 시점의 만기 전 잔존 일수 (예: 만기 5일 전 시점이면 `5` 입력).
  - `-v / --vol-change` (실수): 분석 시점의 변동성(IV) 변화율 (예: `+5%p` 이면 `5` 또는 `0.05` 입력, `-3%p` 이면 `-3` 또는 `-0.03` 입력).
  - `-r / --rate` (실수): 무위험 이자율 % (예: `4.0%` 이면 `4.0` 또는 `0.04` 입력, 기본값: `4.0%`).
  - `-s / --target-underlying` (실수): 예상가 및 포트폴리오 상세 손익 분석을 위한 특정 기초자산 가격 ($).

#### 1. 단일 옵션의 만기 전 예상가 및 예상 손익율 산출
`-d` 와 `-s` 파라미터를 단일 조회 모드와 함께 지정하면, 현재 시세로 계산된 내재변동성(IV)을 바탕으로 해당 시점의 예상 옵션 가격과 손익 시뮬레이션 결과를 텍스트로 상세 출력합니다.

```bash
# AAPLZ26 C440.0 콜옵션에 대해 만기 5일 전 기초자산 가격이 $438.0일 때의 예상 옵션가 및 손익 분석
python trading_option.py "AAPLZ26 C440.0" -d 5 -s 438
```

#### 2. 포트폴리오 합성 수익 곡선 (만기 시점 vs 만기 전 시점 비교 시각화)
`-p` 옵션에 만기 전 분석 파라미터(`-d`, `-v`, `-r`, `-s`)를 함께 지정하면, **만기 시점 수익 곡선(점선)**과 **만기 전 특정 날짜의 예상 수익 곡선(실선)**이 차트에 함께 표시됩니다. 또한, `-s`로 입력된 특정 가격 시나리오에서의 개별 옵션 및 포트폴리오 총 예상 손익 상세 표가 함께 출력됩니다.

```bash
# 콜 불 스프레드 포트폴리오에 대해 만기 5일 전, 변동성이 5%p 상승했을 때의 시각화 및 기초자산 가격 $310 시나리오 분석
python trading_option.py -p "AAPLZ26 C300.0:buy:1" "AAPLZ26 P310.0:sell:1" -d 5 -v 5 -s 310
```

## 4. 거래량 부족 시 보완책 (Mid Price & Fallback 하이브리드 로직)
옵션 거래량이 적은 경우 직전 체결가(`last_price`)가 현재 시점을 제대로 반영하지 못하는 문제를 보완하기 위해 다음과 같은 단계별 프리미엄 산정 알고리즘을 사용합니다:
1. **호가 중간가(Mid Price) 우선 반영**: 매수호가(`bid_price`)와 매도호가(`ask_price`)가 모두 유효하면 이들의 중간값을 옵션 가치로 사용합니다.
2. **호가 스프레드 경고**: 매수/매도 호가 차이가 비정상적으로 넓은 경우(중간값의 50% 초과) 콘솔에 경고를 표시합니다.
3. **현재가 및 전일정산가(Settlement Price) Fallback**: 호가가 없는 경우 직전 체결가를 사용하며, 이마저도 유효하지 않은 경우 거래소 전일정산가(`sttl_price`)를 활용해 누락 없는 내재변동성(IV) 연산 및 시뮬레이션을 보장합니다.

### 미국주식옵션 종목코드 규칙 (한국투자증권 독자 규격)
한국투자증권은 미국 옵션 표준(OCC) 코드를 직접 사용하지 않고, 아래와 같은 독자적인 규칙으로 재구성한 코드를 요구합니다.

`[주간옵션 구분접두사(선택)]` + `[기초자산 티커]` + `[만기월물코드]` + `공백` + `[콜/풋]` + `[행사가격]`

1. **주간옵션 구분접두사 (선택)**: 
   - 매월 셋째 주 금요일 만기인 **표준 옵션(Monthly)**은 접두사 없이 바로 티커로 시작합니다.
   - 매주 만기가 있는 **주간 옵션(Weekly)**은 주차 구분을 위해 숫자가 붙습니다. (예: `1` = 1주차 주간 옵션, `2` = 2주차 주간 옵션 등)

2. **기초자산 티커**: 기초자산의 티커명을 공백 없이 그대로 붙집니다.
   - 예: `AAPL`, `TSLA`, `NVDA`, `PG`
3. **만기월물코드 (3자리)**: 만기월(알파벳 1자) + 만기연도(숫자 2자)
   - 만기월 알파벳 매핑: 1월(F), 2월(G), 3월(H), 4월(J), 5월(K), 6월(M), 7월(N), 8월(Q), 9월(U), 10월(V), 11월(X), 12월(Z)
   - 예: 2026년 7월 만기 -> `N26`
4. **옵션 구분 (1자리)**: 콜옵션은 `C`, 풋옵션은 `P` (앞에 공백 1칸이 들어갑니다.)
5. **행사가격**: 소수점을 포함한 실제 가격을 문자열 그대로 사용합니다.
   - 예: $145.00 -> `145.0`
   - 예: $10.00 -> `10.0`

**예시 조합**:
- Procter & Gamble(PG) 2026년 7월 만기 콜옵션 행사가 $145.0: `"1PGN26 C145.0"`

## 4. 프로젝트 폴더 구조
정리된 프로젝트의 파일 레이아웃은 다음과 같습니다.

```text
├── src/                      # 소스코드 모듈 디렉터리
│   ├── config.py             # 설정 변수 및 경로 매핑
│   ├── pricing.py            # 옵션 가격결정 모형(블랙숄즈)
│   ├── kis_client.py         # KIS API 통신 및 호가 보완 로직
│   ├── master.py             # 마스터 파일 관리 및 파싱
│   └── chart.py              # Matplotlib 시각화 엔진
├── data/                     # 대용량 종목 마스터 및 토큰 캐시 디렉터리
│   ├── .token_cache.json
│   └── fostkcode.mst
├── docs/                     # API 명세서 등 참고 문서 디렉터리
│   └── 한국투자증권_오픈API_전체문서_20260705.xlsx
├── output/                   # 최종 산출 차트 이미지 디렉터리
│   └── payoff_diagram.png
├── trading_option.py         # 실행 엔트리포인트 스크립트
├── .env                      # API 인증 환경설정 파일
└── README.md
```

## 5. 자동 마스터 파일 관리
프로그램 실행 시 `data/fostkcode.mst` 마스터 파일이 없거나 오늘 생성된 파일이 아닌 경우, 한국투자증권 공식 서버([fostkcode.mst.zip](https://new.real.download.dws.co.kr/common/master/fostkcode.mst.zip))에서 **자동으로 최신 마스터 파일을 `data/` 디렉터리에 다운로드 및 압축 해제**하여 캐싱합니다. 사용자가 직접 수동으로 다운로드하거나 파일을 이동할 필요가 없습니다.

## 6. 시세 해석 주의사항
한국투자증권 API로부터 수신한 옵션 현재가 수치(`last_price`)는 종목 마스터 파일(`data/fostkcode.mst`)에 정의된 **계산 소수점(sCalcDesz)**의 배율에 따라 실제 값과 다르게 보일 수 있습니다. (예: API 수신값이 `7525`이고 계산소수점이 `-2`일 경우 실제 가격은 `75.25`입니다.)
