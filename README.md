# 한국투자증권 미국주식옵션 시세조회 프로그램

한국투자증권 Open API를 활용하여 미국주식옵션(해외옵션)의 시세를 조회하는 파이썬 프로그램입니다.

## 1. 사전 준비 (Conda 가상환경 및 패키지 설치)

필요한 패키지(`requests`, `python-dotenv`)가 활성화된 conda 가상환경에 이미 설치되어 있습니다. 만약 다른 환경에서 실행하거나 재설치해야 하는 경우 아래 명령어를 실행하십시오.

```bash
pip install requests python-dotenv
```

## 2. API 설정

1. 프로젝트 루트 폴더에 있는 `config.env.template` 파일을 복사하여 `.env` 또는 `config.env` 파일을 생성합니다.
2. 한국투자증권 Developers 센터에서 발급받은 실전투자용 `APP_KEY`와 `APP_SECRET`을 설정 파일에 입력합니다.

> **주의**: 한국투자증권 해외옵션 조회 API는 **실전투자** 환경에서만 조회 가능하며, 모의투자는 지원하지 않습니다.

```env
APP_KEY=발급받은_실전투자_APP_KEY
APP_SECRET=발급받은_실전투자_APP_SECRET
CUST_TYPE=P
```

## 3. 실행 방법 (시세 조회)

명령 프롬프트(CMD) 또는 파워셸(PowerShell)을 열고 아래와 같이 실행합니다. 
종목 코드 중간에 공백이 포함되어 있으므로 **반드시 따옴표(`"`)로 감싸서 입력**해야 합니다.

```bash
python trading_option.py "AAPL  240719C00180000"
```

### 미국주식옵션 종목코드 규칙 (OCC 규격)
미국주식옵션의 종목코드는 총 21자리로 구성되며, 다음과 같은 고유 규칙을 가집니다:

1. **기초자산 티커 (6자리)**: 티커명이 6자리보다 짧은 경우 우측에 공백을 채워야 합니다.
   - 예: `AAPL  ` (AAPL 뒤에 공백 2개)
   - 예: `TSLA  ` (TSLA 뒤에 공백 2개)
   - 예: `NVDA  ` (NVDA 뒤에 공백 2개)
2. **만기일 (6자리)**: `YYMMDD` 형식
   - 예: 2024년 7월 19일 만기 -> `240719`
3. **옵션 구분 (1자리)**: 콜옵션은 `C`, 풋옵션은 `P`
4. **행사가격 (8자리)**: 소수점 3자리를 포함하여 총 8자리를 맞추어야 합니다 (달러 단위 5자리 + 센트 단위 3자리).
   - 예: 행사가 $180.00 -> `00180000` (앞에 `00180` + 뒤에 `000`)
   - 예: 행사가 $182.50 -> `00182500` (앞에 `00182` + 뒤에 `500`)

**예시 조합**:
- 애플(AAPL) 2024년 7월 19일 만기 콜옵션 $180.00: `"AAPL  240719C00180000"`

## 4. 시세 해석 주의사항
한국투자증권 API로부터 수신한 옵션 현재가 수치(`last_price`)는 종목 마스터 파일(`fostkcode.mst`)에 정의된 **계산 소수점(sCalcDesz)**의 배율에 따라 실제 값과 다르게 보일 수 있습니다. (예: API 수신값이 `7525`이고 계산소수점이 `-2`일 경우 실제 가격은 `75.25`입니다.)
